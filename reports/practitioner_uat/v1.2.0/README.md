## 실행 순서

1. `릴리스_체크` 시트에서 버전, 커밋, Graph build ID와 해시가 현재 앱과 일치하는지 확인한다.
2. `실행큐_75` 시트의 순서대로 새 채팅에서 각 질문을 실행한다.
3. P0 문항은 1·2회차가 각각 별도 행으로 준비되어 있으므로 서로 다른 새 채팅에서 실행한다.
4. 응답 생성이 모두 끝난 뒤 실제 말풍선에 남은 답변 전문, 출처, 종합 점수와 `최종 말풍선 답변 점수`를 행별로 기록한다.
5. `대화_연속성` 시트의 8개 시나리오는 같은 채팅 안에서 순서대로 실행한다.
6. `온톨로지_경계` 시트에서 승인 6개와 정확한 17개 별칭이 검색되는지, 거절 10개와 금지 표현이 노출되지 않는지 확인한다.
7. `실행_대시보드`의 릴리스 게이트 결과를 확인한다.

테스트를 시작하기 전에 근거 배지에 마우스를 올렸을 때 검색 청크가 보이고, 배지를 클릭했을 때 인증된 원본 PDF의 해당 페이지가 새 탭 또는 새 창으로 열리는지 확인한다.

## 최종 말풍선 답변 품질 평가

일반 질의의 답변 품질은 응답 스트리밍이 끝난 뒤 실제 말풍선 안에 남아 실무자가 읽을 수 있는 최종 답변만 대상으로 한다. 모델 내부 생각, 숨겨진 추론, 서버 로그, 스트리밍 중간 상태 문구는 평가에 포함하지 않는다.

`실행큐_75`의 `최종 말풍선 답변 점수`에는 다음을 종합해 1~5점을 입력한다.

- 질문 적합성·직접성: 질문에 먼저 답하고 다른 업무 주제로 이탈하지 않는가
- 사실 정확성·근거 일치: 결론·수치·용어가 표시된 근거 및 출처 권위와 일치하는가
- 조건·예외 완결성: 세대, 급여/비급여, 입원/통원, 증빙 등 판단을 바꾸는 조건을 빠뜨리지 않았는가
- 표시 완결성: 답변이 중간에 잘리거나 표·문장이 미완성되지 않고 중복 블록 없이 끝까지 표시되는가
- 실무 가독성·내부 문구 비노출: 자연스러운 한국어로 바로 활용할 수 있고 내부 태그·프롬프트·생각 문구가 보이지 않는가

말풍선 답변이 절단되거나 내부 생각·프롬프트가 노출되면 내용 일부가 맞더라도 2점 이하로 판정한다. 근거 없는 지급 결론·금액·조건을 확정하면 1점 및 P0 결함 검토 대상이다.

## 합격 기준

- P0 문항: 모든 실행 점수 4점 이상
- 전체 실행 평균: 4.3점 이상
- 1~2점 결함: 0건
- 최종 말풍선 답변 P0: 전건 4점 이상
- 최종 말풍선 답변 전체 평균: 4.3점 이상
- 최종 말풍선 답변 1~2점 및 실행 후 미평가: 0건
- 온톨로지 경계 10개: 전부 PASS
- 대화 연속성 8개: 전부 PASS
- 근거가 없거나 모호한 경우에는 추정 결론 대신 확인 질문 또는 보류 안내가 나와야 한다.
- 수술종수, 수가코드, 진단코드, 계산 결과가 서로 다른 의도로 혼동되지 않아야 한다.

하나라도 실패하면 릴리스 자체를 즉시 되돌리기보다 해당 문항의 검색 경로, Graph 근거, 문서 출처, 대화 상태를 먼저 분류한다. 계산 룰 변경은 별도 실무 승인 없이는 수행하지 않는다.

## 시트 설명

- `릴리스_체크`: 실행 대상 버전과 데이터 해시 확인
- `판정_기준`: 종합 1~5점 기준, 결함 분류, 최종 말풍선 답변 전용 평가 기준
- `실행큐_75`: 64개 고유 문항을 P0 반복 실행까지 포함해 75개 실행 행으로 펼친 기록란. 종합 점수와 최종 말풍선 답변 점수를 별도로 기록한다.
- `원본_76`: 두 평가자료의 원본 행 보존
- `대화_연속성`: 후속 질문 및 계산에서 일반 질의로 이어지는 흐름 검증
- `온톨로지_경계`: 승인·거절·금지 표현 검증
- `실행_대시보드`: 진행률과 릴리스 게이트 집계

## 보류된 항목

실제 DGX 데스크톱 브라우저에서의 물리적 GUI UAT는 사용자 요청에 따라 이번 작업의 남은 항목으로 보류한다. 이 문서는 테스트 설계와 실행 준비 완료를 의미하며, 실무자 실행 결과 자체를 의미하지 않는다.
