## 출처 상호작용

4세대 한도 답변의 출처 배지를 대상으로 확인했다.

- **호버:** 통과. 마우스를 올리면 선택 근거의 축약 청크가 표시됐고, `300만원 이내에서 보상` 문구가 보였다.
- **클릭:** 통과. 새 PDF 탭이 열렸고 URL의 `#page=71`과 Chrome PDF 뷰어의 페이지 표시 `71 / 172`가 일치했다.
- **원문:** 4세대 약관 제3조(보장종목별 보상내용)의 p.71이 정상 표시됐다.

## 확인된 결함

1. **최종 말풍선 답변의 실무 품질 미달**
   - 직접 질문한 한도·비교 결과를 첫 문장에 명확히 답하지 않는다.
   - OCR 원문을 과도하게 덤프하여 어떤 수치가 질문의 답인지 실무자가 즉시 판단하기 어렵다.

2. **내부 메타데이터 및 내부 판단 문구 노출**
   - `chunk=...`, `source=text`, `직접 연결된 판단 조건 경로...`, `【세대 정의 충돌】`이 실제 사용자 말풍선에 표시된다.
   - 이는 UAT 안내서의 최종 말풍선 품질 기준을 직접 위반한다.

3. **보장 판단 경계의 사실 오류 및 지연**
   - `5세대 MRI 연간 보장되나요?`는 응답 완료까지 약 50초가 걸렸다.
   - 등록된 표준약관이 있음에도 5세대 규정이 없다는 취지의 답변이 노출됐다.

## 유지 확인

- 4세대 `300만원`, 5세대 `200만원`의 원문 회수 자체는 성공했다.
- 5세대 한도는 별도 새 채팅 두 번에서 동일하게 재현됐다.
- 비교 질의에서 두 세대의 근거는 함께 회수됐다.
- 지급 판단 질의는 지급을 단정하지 않고 추가 사실 확인을 요구했다.
- 출처 호버 및 인용 페이지 PDF 열기 기능은 정상 동작했다.
- 이번 UAT 중 GraphDB, 온톨로지, 액티브 계산 룰, 원문 자료, 운영 데이터는 변경하지 않았다.

## 후속 권고

1. **P0 우선:** 최종 응답 조립 단계에서 공개 답변과 내부 근거/진단 데이터를 분리한다. 특히 직접 약관 속성 질의는 `결론 → 적용 조건 → 출처` 순서의 짧은 사용자용 답변을 만들고, 원시 청크 식별자와 내부 상태 문자열은 렌더링 전에 제거해야 한다.
2. **P0 우선:** 보장·청구·지급 판단 질의가 선택 세대의 등록 문서를 놓치지 않도록 검색 경로를 재점검한다. 근거가 불충분하면 확인 질문만 표시하고, 존재하는 표준약관을 `없음`으로 진술해서는 안 된다.
3. 위 두 항목을 수정·독립 리뷰한 뒤, 동일한 Chrome 핵심 UAT를 다시 실행한다. 통과 전에는 전체 75회 UAT, `v1.2.0` 태그 정합화, 릴리스 승인으로 진행하지 않는다.
