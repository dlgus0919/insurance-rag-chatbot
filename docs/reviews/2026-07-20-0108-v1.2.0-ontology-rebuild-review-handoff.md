## 개발 중 발견하고 수정한 결함

1. 첫 Graph attempt에서 ontology JSON을 canonical document JSONL 인자로 전달해 JSON decode 실패. concept manifest와 document manifest CLI 인자를 분리하고 잘못된 입력을 거부하는 회귀를 추가했다.
2. attempt2에서 승인 표현이 `candidate_aliases`에만 남아 Graph alias로 seed되지 않음. 실무자가 승인한 17개 표현만 active aliases로 승격하고 attempt3을 새 경로에 재빌드했다.
3. 신규 planner 필드 3개가 기존 `OntologyConcept` 위치 인자 순서를 바꿈. 모든 기존 필드 순서를 유지하고 새 기본값 필드를 마지막에 배치했으며 구 생성자 회귀를 추가했다.
4. 기존 탈모 planner 테스트가 active runtime manifest를 forensic fixture처럼 사용. 원래 assertion은 약화하지 않고 명시적 test-local fixture로 분리했으며, 기본 runtime에서 미승인 탈모 6개와 결정 경로가 부재함을 별도 테스트로 고정했다.
5. 후보 release 초기 검토 권한과 관리자 시각화 snapshot 누락은 후보 경로에 한해 group read/execute 권한과 bounded snapshot을 추가해 보정했다. group write/world 권한은 없어야 한다.
