## Chrome 재현 결과

### 5세대 직접 한도 질의

- 질문: `5세대 자기공명영상진단(MRI/MRA)의 연간 보상한도는?`
- 새 채팅에서 2회 반복
- 두 번 모두 핵심값 `200만원`과 표준약관 직접 출처를 답함
- 불필요한 방문 구분/증빙 질문은 없었음
- 결함: 최종 말풍선 본문에 `【claim_condition_review】 직접 연결된 판단 조건 경로를 찾지 못했습니다.`가 노출됨

### 4세대 직접 한도 질의

- UI에서 `4세대 실손`을 명시 선택한 새 채팅
- 질문: `4세대 자기공명영상진단(MRI/MRA)의 연간 보상한도는?`
- 기대: `연간 300만원`과 4세대 직접 근거
- 실제: `【claim_condition_review】 ... 【generation_rule_review】 ... ---.`만 출력
- 핵심 한도값과 설명이 완전히 누락됨
- 출처 목록은 표시됐으나 최종 답변 자체가 요구에 응답하지 못함

## 판정

- 5세대: 핵심값 PASS, 최종 답변 품질 FAIL
- 4세대: P0 FAIL
- P0 확인 즉시 비교 질의와 보상 여부 변형 질의 실행을 중단함

1. 4세대와 5세대의 요청 세대가 검색, 근거 선택, 답변 합성 단계에서 각각 어떻게 전달되는지 실제 로그와 코드 경로로 추적한다.

3. 내부 구조화 경로 태그와 placeholder(`---`)가 최종 사용자 말풍선에 노출되는 일반 원인을 수정한다.
