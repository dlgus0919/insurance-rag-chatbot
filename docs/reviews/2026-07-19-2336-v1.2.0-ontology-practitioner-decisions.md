- 판정 시각: 2026-07-19 23:36 KST
- 판정자 역할: 보험금 보상 실무자 관점의 Planner 직접 판정

- 적용 제외: 보험금 계산 결과, 공제율, 지급액, 지급 여부 자동 확정, active 계산 규칙

## 판정 원칙

1. 원문 청크와 문서 권위가 식별되는 재사용 가능한 보험 업무 개념만 승인한다.
2. 질문 문장, 개별 사례 답변, 금액·비율·기한 숫자, 지급 결론은 개념 payload에 넣지 않는다.
3. 서로 다른 문서 권위, 제도 또는 판단 결과를 동의어로 합치지 않는다.
4. 승인 개념은 검색 및 추가 확인 경로에만 사용하며 계산·지급 planner hook을 만들지 않는다.
5. 기존 trusted 49개는 그대로 보존하고, provenance가 부족한 탈모 관련 6개는 계속 제외한다.

### 3. `cond.policy_source_authority` — 거절

- 제안 정식명: 약관 출처 및 실손 세대 확인
- 거절 필드: 후보 전체
- 근거 검토: 자사 4세대 `약관_ch_002286`, 5세대 표준약관 `표준약관_ch_004925`
- 평가 연계: `new_20260702_035`, `new_20260702_047`
- 이유:
  - `자사 상품 약관`, `표준약관`, `실손 세대`는 서로 동의어가 아니라 별도의 문서 권위와 계약 맥락이다.
  - 하나의 expansion rule로 묶으면 자사 약관 질의에 표준약관을 섞거나 그 반대가 되어 과거 source-authority 오류가 재발할 수 있다.
  - 출처 우선순위와 상품 문서 존재 여부는 이미 별도의 source-authority 로직과 세대 필터가 담당해야 하며, 이번 ontology rebuild에서 중복 우회 경로를 만들지 않는다.
- 후속: 이번 릴리스에는 대체 온톨로지 후보를 만들지 않고, UAT에서 기존 source-authority 경로를 회귀 검증한다.

1. `dev.cov.indemnity_medical.2f8f7057fb90`
   - 거절 이유: `중지 입원의료비로 간주`는 문장 조각이며 실손의 정당한 동의어가 아니다. 연결 원문도 자동차보험 목차·상품 나열로 근거가 맞지 않는다.
2. `dev.cond.motorcycle_riding.fc842c72db6f`
   - 거절 이유: 승용·승합·화물·특수자동차와 일반 자동차사고를 이륜자동차 운전/탑승의 동의어로 합치면 소유 개념이 달라진다.

   - 거절 이유: 근거는 자동차보험의 상급병실 지원특약이며 실손 상급병실료 차액 개념의 직접 근거가 아니다.

## 적용 후 기대 경계

- trusted 기존 개념: 49개
- 승인 신규 개념: 6개(전체 승인 5개 + 부분 승인 1개)
- 예상 runtime projection: 55개

- active claim rule 파일: 내용과 해시 모두 변경 없음

## 구현 및 검증 중단 조건

- 동결한 active 계산 파일 3개의 해시가 달라지면 즉시 중단한다.
- rejected 후보 또는 탈모 6개가 runtime projection이나 Graph에 나타나면 즉시 중단한다.
- 승인 후보가 금액·비율·지급 결과·질문 문장에 대한 case-specific rule을 만들면 즉시 중단한다.
- 전체 GraphDB 빌드가 메모리 안전선 아래로 내려가거나 명확한 종료 원인을 보존하지 못하면 운영 publish 없이 candidate build만 보존하고 보고한다.
- source authority 기존 로직을 ontology expansion으로 우회하거나 자사/표준약관을 혼합하면 즉시 중단한다.
