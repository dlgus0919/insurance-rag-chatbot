**smoke_qa 항목:**

### Q2 — 진단코드 보상 여부 조회 (약관, 단일 문서)

**질문:** N39.3 진단이 실손의료비 약관에서 보상가능한지 알려줘.

**예상 답변:**
> N39.3 진단(요실금)은 약관에서 다음 보장종목 모두에서 보상하지 않는 사항으로 명시되어 있습니다:
> - 질병급여 항목: 보상 불가 [출처: 약관, 제3조(보장종목별 보상내용), p.38]
> - 질병비급여 항목: 보상 불가 [출처: 약관, 제3조(보장종목별 보상내용), p.80]
> - 3대비급여 항목: 보상 불가 [출처: 약관, 별표/3대비급여, p.82]

**검증 포인트:**
- N39.3이 3개 항목 모두에서 보상 불가임을 명시해야 함
- 출처 문서: 약관(2.약관_신한 이지로운 실손의료보험...)
- 참조 페이지: PDF 38p, 80p, 82p
  - ※ 기획자 제공 기준 페이지(37p, 79p, 81p)는 문서 내 인쇄 페이지 기준이며, PDF 파일 인덱스 기준으로는 38p, 80p, 82p임

**smoke_qa 항목:**
```json
{
  "question": "N39.3 진단이 실손의료비 약관에서 보상가능한지 알려줘.",
  "expected_pages": [38, 80, 82],
  "expected_codes": ["N39.3"],
  "doc_sources": ["약관"],
  "type": "code"
}
```

### Q3 — 수술코드 + 수술해설 + 종별 복합 조회 (심평원 + 가이드북)

**질문:** 식도조루술의 수술코드, 수술해설과 1-5종 해당여부를 알려줘.

**예상 답변:**
> 식도조루술의 코드는 Q2333 이며, 식도에 음식을 몸 안으로 넣어주는 통로를 마련해주는 수술방법을 말합니다. 1-5종 수술비에서 3종에 해당합니다.
> [출처: 심평원, p.956 / 보상가이드북, p.107]

**검증 포인트:**
- 수술코드: Q2333 (심평원 956p)
- 수술 해설 내용이 포함되어야 함
- 종별: 3종 (가이드북 107p)
- 출처 2개 문서가 모두 인용되어야 함
- ⚠️ 이 질문은 **보상가이드북 PDF가 인덱싱된 이후에만** 완전한 답변 가능

**smoke_qa 항목:**
```json
{
  "question": "식도조루술의 수술코드, 수술해설과 1-5종 해당여부를 알려줘.",
  "expected_pages": [956],
  "expected_codes": ["Q2333"],
  "doc_sources": ["심평원", "가이드북"],
  "type": "cross_doc",
  "note": "가이드북 미인덱싱 시 종별 정보 없이 부분 답변 예상. doc_sources=['가이드북'] 항목 인덱싱 후 재평가 필요."
}
```
