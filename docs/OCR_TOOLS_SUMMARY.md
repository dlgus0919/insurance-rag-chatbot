# OCR 결과 요약

> 본 프로젝트(보험 문서 RAG 챗봇)에서 실제 검증한 OCR 도구 기준으로 작성.
> 비교 대상: 실무가이드 60–70페이지 스캔본 기준.

---

## PaddleOCR (PP-Structure)

- **장점**: 무료 로컬 실행. 텍스트·표·이미지·제목 영역을 자동 분리하고 bbox, confidence, content_type 메타데이터 생성. 순수 텍스트 페이지의 본문 추출 품질 양호.
- **주요 오류**: 흐린 글자·회색 배경·작은 글씨에서 오인식 발생. 병합 셀·복잡한 표에서 셀 텍스트가 깨지거나 분리됨. figure 영역을 과도하게 넓게 잡아 인접 텍스트 포함 가능.
- **활용가능성**: 1차 레이아웃 분류기로 적합. content_type 기반으로 텍스트 페이지는 직접 활용하고, 표·이미지형 페이지만 CLOVA로 폴백하는 라우팅 설계에 활용 가능.
- **구조인식**: 레이아웃 영역 분리는 우수. 셀 병합·다단 헤더 복원 불가. 표 위치 감지는 성공하지만 셀 텍스트 복원은 불안정.
- **비용**: 무료. 로컬 CPU/GPU 처리. 페이지당 약 1–3초(CPU 기준).

---

## EasyOCR

- **장점**: 설치 간단. 한국어 포함 다국어 지원. 무료.
- **주요 오류**: 보험 약관 등 한국어 전문 텍스트에서 오인식율 상대적으로 높음. 표 구조 인식 없음. 세로 텍스트·작은 글씨 취약.
- **활용가능성**: 본 프로젝트 도메인에는 적합하지 않음. 단순 단일 블록 텍스트 추출 보조 용도에 한정.
- **구조인식**: 레이아웃 분리 없음. 전체 페이지를 단일 텍스트 스트림으로 처리.
- **비용**: 무료. 로컬 처리.

---

## Naver CLOVA OCR (API)

- **장점**: 한국어 특화 모델. Native table 감지(`tables[]`)로 셀별 bbox·row/column span 정보 제공. 텍스트 정확도 높음. 다단 헤더 자동 감지(v45)·그림 셀 Vision 정제(v45)·수술종수 숫자 보정(v47) 적용됨.
- **주요 오류**: 한 획짜리 `1`을 표 세로선으로 오인하여 blank 처리(v47 Vision 정제로 보완). 그림 셀 내부 텍스트를 OCR 값으로 오인식(v45 정제로 보완). API 지연 간헐 발생.
- **활용가능성**: 표 포함 페이지의 핵심 엔진. 단독 또는 True Hybrid 조합으로 사용. 현재 알려진 오인식 패턴은 모두 후처리로 보완 완료.
- **구조인식**: 셀 병합·다단 헤더 자동 복원 가능(v45). Native table 경로가 현재 가장 정확한 표 구조 복원 결과 제공.
- **비용**: API 과금. 페이지당 약 10–15초 처리. CLOVA 요금제에 따라 상이.

## True Hybrid (PP-Structure 레이아웃 + CLOVA OCR)

- **장점**: PP-Structure로 영역을 분리한 후 CLOVA로 각 영역을 정밀 인식 → 레이아웃 분리 정확도와 한국어 OCR 품질 동시 확보. 현재 파이프라인의 기본 운영 모드. 실무가이드 60–70페이지 전체 SUCCESS.
- **주요 오류**: figure 영역은 CLOVA에 전달하지 않아 그림 설명 누락 가능. 처리 시간이 가장 김(페이지당 15–51초). PP-Structure 레이아웃 오류가 CLOVA 결과에 전파됨.
- **활용가능성**: `--vision-clean` 플래그 추가 시 그림 셀·수술종수 누락까지 보완. 현재 운영 파이프라인에 채택. 전체 문서 확장 준비 완료.
- **구조인식**: CLOVA native table + Vision 표 정제(v45) + 숫자 셀 보정(v47) 조합 시 가장 우수. 다단 헤더·병합 셀·그림 셀·수술종수 누락 모두 처리.
- **비용**: CLOVA API 비용 + PP-Structure 로컬 처리 시간. 전체 문서 일괄 처리 시 비용 계획 필요.

## Vision LLM (OpenAI gpt-4o-mini / gpt-4.1)

- **장점**: 사람이 이미지를 보는 방식으로 판독. 그림 셀 감지·수치 누락 보완에 특화. 기존 OCR이 놓친 맥락(한 획짜리 숫자, 도식 셀) 복원 가능. retry 방어 로직 적용. 수술종수 3컬럼을 완성 그룹으로 처리(v47).
- **주요 오류**: 응답이 간헐적으로 invalid JSON shape 반환(1회 retry로 해결 확인). 표 구조 자체를 변경 시도하는 경우 있어 shape 검증 방어 필수. API 비용 발생.
- **활용가능성**: `--vision-clean` 플래그로 선택적 적용. 표 정제(그림 셀)와 숫자 정제(수술종수)를 순차 호출. 전체 페이지 자동 처리보다 품질 보정 단계에 적합.
- **구조인식**: 표 전체 이미지 기반 재판독. 셀 구조를 직접 생성하지 않고 기존 OCR JSON을 보조 수정하는 역할. 원본 JSON 구조(headers·rows) 유지 강제.
- **비용**: 표 1개당 약 $0.001–0.005 추정(gpt-4.1 기준). 전 페이지 적용 시 비용 계획 필요.
