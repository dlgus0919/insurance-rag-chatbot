## 8. 권장 개선 방법

1. **페이지 전체를 한 번에 읽지 말고 표를 행 단위로 분할한다.**
   4번 이미지 재처리 결과처럼 세로 분할만 적용해도 코드와 행 인식이 개선됐다.

2. **코드 열은 전용 규칙으로 처리한다.**
   같은 셀의 첫 줄과 두 번째 줄을 공백 없이 결합하고, 허용된 진료 코드
   사전과 대조해야 한다.

3. **명칭은 OCR 결과보다 코드 사전을 우선한다.**
   코드를 정상화한 후 병원 수가·약품·치료재료 코드 사전에서 공식 명칭을
   조회하면 긴 명칭의 환각과 철자 오류를 줄일 수 있다.

4. **금액 산식 검증을 자동화한다.**
   `단가 × 횟수 × 일수 = 총액`인지 확인하고, 본인부담금·공단부담금·
   전액본인부담금·비급여의 합이 총액과 맞는지 검사한다.

5. **영수증은 고정 좌표 템플릿으로 인식한다.**
   현재처럼 언어 모델이 행 이름과 숫자를 함께 재구성하게 두면 행 이동이
   발생한다. 표의 좌표를 먼저 검출한 뒤 각 셀을 독립적으로 읽어야 한다.

6. **문서 간 교차 검증을 적용한다.**
   진단명·질병분류기호·수술명·수술일은 진단서와 수술확인서가 일치하는지,
   영수증 총액은 세부내역서 최종 합계와 일치하는지 확인한다.

7. **위험 값에는 사람 검수 단계를 둔다.**
   코드 사전 불일치, 산식 불일치, 진단 구분 불일치, 합계 불일치가 하나라도
   있으면 자동 계산을 중단하고 검수 대상으로 보내는 것이 안전하다.

## 9. 최종 판단

Gemma 4 31B의 이번 OCR 결과는 다음 용도로는 충분히 의미가 있다.

- 의료문서 종류 자동 분류
- 필요한 표와 핵심 필드의 위치 파악
- 진단명·질병분류기호·수술명 후보 추출
- 결제 총액과 세부내역 총액의 1차 추출

하지만 코드 완전 일치율이 약 60.6%이고 영수증 항목별 금액의 행 이동이
확인되었으므로, 현재 엑셀을 그대로 보험금 계산 로직에 연결하는 것은 권장하지
않는다.

현실적인 최적 방법은 **Gemma 4 31B를 문서 이해와 필드 후보 추출에 사용하고,
표 셀 OCR·코드 사전·산식 검증·문서 간 교차 검증을 결합하는 방식**이다.
