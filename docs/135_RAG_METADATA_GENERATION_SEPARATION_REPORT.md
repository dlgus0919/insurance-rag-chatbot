# 135. 실손 4/5세대 메타데이터 분리 및 프롬프트 주입 보고

작성일: 2026-05-27

## 목적
약관(신한 이지로운 실손의료보험) 및 표준약관 문서에 대해 각각 4세대, 5세대 메타데이터를 부여하여 벡터 DB 검색 및 LLM 답변 생성 시 이를 반영할 수 있도록 개선합니다. 이를 통해 LLM이 질문을 해석할 때 참조 문헌이 몇 세대 실손 기준인지 명확하게 파악하여 환각을 방지하고 RAG 답변의 정합성을 높입니다.

## 수정 내역

### 1. 설정 및 메타데이터 필드 추가 (src/config.py)
- PdfSource 데이터 클래스에 policy_generation: str | None = None 필드 추가
- '신한 이지로운 실손의료보험' 문서: policy_generation='4th' 추가
- '표준약관' 문서: policy_generation='5th' 추가

### 2. 인제스트 파이프라인 연동 (src/parser/chunker.py)
- EXTENDED_META_FIELDS 리스트에 'policy_generation'을 추가
- Chunk 생성 시 이 정보가 ChromaDB 및 BM25 메타데이터에 자동 저장되도록 구조 확장

### 3. LLM 프롬프트 주입 (src/llm/prompt.py)
- _context_label 함수: 컨텍스트 라벨에 세대 정보가 있으면 [약관(4세대)] 형태로 렌더링되도록 수정
- format_source_citation 함수: 답변 출처 표기 시 [출처: 약관(4세대), p.42] 등으로 세대 정보가 출력되도록 반영
- build_user_prompt 함수: LLM이 컨텍스트를 읽을 때 [약관(4세대)]로 읽어 질문과 매칭할 수 있도록 헤더 보강

### 4. 재색인 및 서버 재가동
- 변경된 메타데이터를 반영하기 위해 전체 문서를 재생성(scripts/ingest.py --stage all)하여 DB를 업데이트했습니다.
- 백엔드 서비스(Uvicorn)를 재시작하여 변경된 프롬프트와 검색 시스템이 적용되도록 완료했습니다.

## 검증 결과
- 수정 후 자동화 테스트 스위트가 모두 성공(Passed)했습니다.
- 인덱스 재색인 작업이 백그라운드에서 완료되었으며, API 서버가 새로운 프롬프트 모듈을 정상적으로 임포트하여 구동 중입니다.
