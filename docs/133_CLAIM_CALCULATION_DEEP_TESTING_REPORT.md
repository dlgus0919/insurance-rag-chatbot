# 133. 보험금 계산 기능 심화 테스트 보고

작성일: 2026-05-26

## 목적

보험금 계산 기능이 단일 도수치료 예시를 넘어 실제 보상 신청에 가까운 다양한 상황에서 안정적으로 계산되는지 확인했다. 특히 4세대/5세대 실손 기준이 같은 결과를 내는 경우와 달라지는 경우, 통원 최소공제, 상급병실료 차액, 건강보험/의료급여 미적용 특례, 복수 항목 합산, LLM 생성 계산 코드의 샌드박스 실행 경로를 테스트로 고정했다.

## 추가한 심화 시나리오

1. 4세대/5세대 동일 결과
   - 급여 통원 진료비: 양 세대 모두 20% 공제.
   - 산정특례 중증 비급여: 4세대 비급여와 5세대 중증 비급여 모두 30% 공제.

2. 4세대/5세대 차등 결과
   - 비중증 비급여 200,000원 통원:
     - 4세대: 30% 공제, 지급예상액 140,000원.
     - 5세대: 50% 공제, 지급예상액 100,000원.

3. 최소공제 경계값
   - 급여 통원 30,000원: 20%보다 최소공제 10,000원이 우선 적용.
   - 4세대 비급여 통원 50,000원: 30%보다 최소공제 30,000원이 우선 적용.
   - 5세대 비중증 비급여 통원 50,000원: 최소공제 50,000원이 적용되어 지급예상액 0원.

4. 특례/특이 적용
   - 상급병실료 차액: 1일 평균 100,000원 한도와 50% 보상 규칙 적용.
   - 건강보험/의료급여 미적용: 통원 공제 후 금액의 40% 보상 특례 적용 및 검토 플래그 유지.
   - 정보 부족/보상 제외: 계산 확정 대신 검토 사유를 남김.

5. 복수 항목 청구
   - 진료비 영수증/세부내역서처럼 급여, 비중증 비급여, 상급병실료 차액이 섞인 하나의 청구 건을 항목별로 계산하고 총합을 검증.

6. LLM 생성 계산 코드 실행
   - `use_fake_planner=False` 경로에서 LLM이 반환한 서로 다른 `formula_intent` 코드가 AST 샌드박스에서 정상 실행되는지 검증.
   - 4세대 비급여 통원, 5세대 비중증 비급여 통원, 상급병실료 차액 한도, 건강보험/의료급여 미적용 40% 특례의 코드 형태를 각각 검증.
   - 이 과정에서 LLM 계산 성공 경로의 `sandbox_error_occurred` 초기화 누락 버그를 발견하고 수정.

## 남은 주의점

- 현재 계산기는 약관의 대표 공제/특례 산식을 결정론적으로 적용한다. 실제 심사에서는 가입 담보, 보험가입금액, 연간/회당 한도 잔여분, 다수보험 비례보상, 과거 청구 이력까지 필요하므로 해당 정보가 없는 경우 검토 플래그를 유지해야 한다.
- 5세대 비급여는 산정특례 대상 여부에 따라 중증/비중증 구분이 달라진다. UI에서 `중증비급여`, `비중증비급여` 힌트를 제공하지만, 실제 계산 확정은 진단/산정특례 및 진료비 세부내역서 확인이 필요하다.
