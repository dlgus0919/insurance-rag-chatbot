# 테스트 시나리오 및 평가 가이드

> **문서 유형:** 기획자 작성 테스트 설계 문서
> **작성일:** 2026-05-04
> **대상 문서:** 심평원(건강보험 행위 급여·비급여 목록표 및 급여 상대가치점수) + 약관(신한 이지로운 실손의료보험(무배당))
> **독자:** 기획자(수동 테스트), 향후 자동 eval 확장 기반 자료

---

## 1. 테스트 설계 원칙

### 커버리지 목표

이 가이드는 두 문서의 핵심 기능 영역을 **4개 레벨**로 분류하여 테스트합니다:

| 레벨 | 유형 | 설명 | 목표 정답률 |
|------|------|------|------------|
| L1 | 단순 코드/수치 조회 | 코드를 넣으면 명칭·점수가 나오는가 | 95%+ |
| L2 | 규정 해석 | 조건부 산정 기준, 가산율 판단 | 85%+ |
| L3 | 보상 판단 | 진단코드·치료행위의 보상 가능 여부 | 80%+ |
| L4 | 복합·멀티턴 | 두 문서 교차, 연속 질문 | 70%+ |

### 평가 기준 체계

각 시나리오마다 아래 기준으로 평가합니다:

- ✅ **정답**: 핵심 정보가 모두 정확하게 포함됨
- ⚠️ **부분 정답**: 핵심 정보 일부 포함 (허용 조건 명시)
- ❌ **오답**: 핵심 정보가 틀리거나 없음
- 🔄 **스킵**: 인덱스 미포함 문서 등 데이터 부족으로 현재 불가

## 4. 테스트 시나리오 — 복합·멀티턴 (L4)

### 4-A. 심평원 + 약관 교차 질의

#### T23 — 진찰료 + 실손 보상 교차

**질문:** AA157 상급종합병원 초진 진찰료는 실손보험에서 보상받을 수 있나요?

**필수 포함 요소:**
- 심평원 급여 항목임을 확인
- 실손보험 급여 파트에서 보상 가능 여부
- 두 문서 출처 모두 인용 (이상적 답변)

**부분 정답 허용:** 심평원 출처 또는 약관 출처 중 하나만 인용해도 ⚠️

---

#### T24 — 비급여 주사료 + 약관 한도

**질문:** 비급여 주사 치료를 받았을 때 심평원 기준과 실손 약관 기준이 어떻게 다른가요?

**필수 포함 요소:**
- 비급여 주사료 관련 설명 (심평원 또는 약관 중 하나 이상)

**참고:** 이 질문은 두 문서를 비교하는 고난도 질문으로, 부분 정답 허용 범위를 넓게 설정.

### 4-B. 멀티턴 연속 질문

#### T25 — 3대비급여 세부 항목 연속 질문

**대화 흐름:**

1단계 질문: "실손의료보험 약관에서 3대비급여에 해당하는 항목은 무엇인가요?"
> 기대: 도수치료·체외충격파·증식치료 / 비급여 주사료 / MRI·MRA 열거

2단계 질문: "그렇다면 3대비급여 중 도수치료의 보상 한도는 어떻게 되나요?"
> 기대: 350만원, 50회 정보 포함

3단계 질문: "도수치료에서 1회당 공제금액은 얼마인가요?"
> 기대: 3만원과 보장대상의료비의 30% 중 큰 금액

**확인 포인트:**
- 각 단계 답변이 이전 컨텍스트를 유지하는가
- 대화 초기화 버튼 클릭 후 히스토리가 리셋되는가

---

#### T26 — 수술코드 조회 후 보상 판단

**대화 흐름:**

1단계 질문: "식도조루술의 코드를 알려줘."
> 기대: Q2333 포함

2단계 질문: "방금 답변한 수술의 실손 약관 보상 여부는?"
> 기대: 해당 수술코드의 급여/비급여 여부와 실손 보상 조건 설명

**확인 포인트:**
- 이전 대화에서 언급한 Q2333을 참조하는가 (멀티턴 이해)

## 5. 경계 케이스 (Edge Case) 시나리오

#### T27 — 존재하지 않는 코드

**질문:** ZZ999 코드의 진찰료 점수는 얼마인가요?

**기대 동작:**
- "제공된 문서에서 확인되지 않습니다." 또는 유사 표현
- 잘못된 코드를 가져와 오답 생성하지 않을 것

---

#### T28 — 모호한 질문 (두 문서 모두 해당 가능)

**질문:** 진찰료 보상은 어떻게 되나요?

**기대 동작:**
- "심평원 기준" 또는 "약관 기준" 중 어느 것을 묻는지 명확하지 않음
- 이상적으로는 두 관점을 모두 설명하거나 어느 쪽을 원하는지 안내
- 오답(엉뚱한 정보) 생성하지 않으면 ⚠️ 이상으로 평가

---

#### T29 — 긴 조문 정확 추출

**질문:** 실손보험 약관에서 제3조 보장종목별 보상내용의 질병급여 항목에서 보상하지 않는 사항을 모두 나열해줘.

**기대 동작:**
- 질병급여 파트의 보상 제외 항목 열거
- 컨텍스트 윈도우 한계로 일부만 반환될 수 있음 → ⚠️ 허용

---

#### T30 — 한글 명칭으로 코드 역조회

**질문:** "상급종합병원 초진 진찰료"에 해당하는 코드는 무엇인가요?

**기대 동작:**
- 코드 AA157 반환
- 명칭 → 코드 역방향 조회가 성공하면 ✅

## 6. 평가 실행 방법

### 6-1. 수동 테스트 절차

```
1. streamlit run src/ui/streamlit_app.py
2. http://localhost:8501 접속
3. 사이드바에서 모델 선택, Top-K=8, 온도=0.2 설정
4. 아래 시트 순서대로 질문 입력
5. 각 질문마다 판정(✅⚠️❌) 기록
6. 멀티턴 시나리오는 반드시 새 대화에서 시작
```
