# v1.2.0.b Qwen 우선 응답 핫픽스

## 목적

일반 문서 검색에서 직접 조항 또는 결정형 근거가 발견된 경우, 결정형 산출물이 최종 말풍선으로 그대로 노출되어 대화 맥락을 반영한 설명 생성이 생략되던 문제를 임시 완화한다.

## 변경 범위

- 일반 문서 검색 응답도 선택된 Qwen 스트림을 항상 호출하도록 변경했다.
- 결정형 산출물은 검색·근거 메타데이터로만 유지하며 최종 답변을 대체하지 않는다.
- 화면 버전 표시는 `1.2.0.b`로 변경하고 배포 번들을 재생성한다.

## 변경하지 않은 범위

- 보험금 계산, 승인된 계산 규칙, GraphDB·온톨로지, 원문 자료, 권한·사용자 데이터는 변경하지 않는다.
- 계산·구조화 검토 경로의 안전 보류 정책도 변경하지 않는다.

## 검증

- 결정형 검색 산출물이 있어도 Qwen 스트림을 호출하고 결과를 저장하는 회귀 테스트를 추가했다.
- 5세대 직접 조항 응답에서 과거 대화 보존과 Qwen 최종 답변 저장을 확인했다.
- 프런트엔드 번들을 재생성했다.

## 전체 테스트 현황

전체 `pytest -q`는 1,104건 통과, 27건 실패였다. 실패는 온톨로지 런타임 인덱스의 개념 수가 0으로 로드되는 기존 환경 상태와 그에 의존하는 GraphDB 경로 테스트에 집중되어 있으며, 이번 변경 파일과 계산 규칙에는 관련 변경이 없다. 이 핫픽스의 대상인 채팅 스트림 회귀 테스트 2건은 통과했다.

## 운영 유의사항

이 버전은 일반 질의의 설명성을 우선하는 임시 핫픽스다. 직접 근거의 존재와 출처 표시는 유지하지만, 최종 서술은 Qwen 생성 결과이므로 `v1.2.0`보다 문구 변동성이 커질 수 있다. 문제 발생 시 `v1.2.0` 태그로 되돌릴 수 있다.
