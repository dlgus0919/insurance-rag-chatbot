# UAT MRI 세대별 한도 답변 회귀 수정 보고서

## 범위

- 대상: 일반 질의에서 선택된 실손 세대와 원문 근거를 이용하는 한도·횟수·기간 조회
- 제외: 활성 계산 룰, 온톨로지, GraphDB, safe-baseline, 운영 데이터와 서비스

## 재현 원인

1. `연간 보상한도`는 직접 원문 수치 조회이지만 조항 세부 조회 범주에 포함되지 않아, 선택 세대의 검색 근거가 있어도 결정적 원문 답변으로 승격되지 않았다.
2. 최종 답변 정리기는 형식화된 검토 템플릿만 제거했고, 내부 경로 식별자(`【claim_condition_review】` 등)와 구분선만으로 구성된 잔여 줄을 제거하지 못했다.
3. 화면의 세대 선택이 Graph/RAG 경로로 전달되는 계약은 기존 회귀로 이미 고정되어 있었다. 이번 수정은 그 선택으로 필터링된 근거를 직접 한도 답변에 사용하도록 연결한다.

## 최소 수정

- `config/clause_detail_lookup_policy.json`에 금액·공제율 없이 일반적인 한도·횟수·기간 근거 용어만 추가했다.
- `src/rag/pipeline.py`가 명시적인 한도·횟수·기간 조회를 원문 수치 기반 조항 세부 조회로 처리하도록 확장했다.
- `src/api/rag_service.py`가 렌더 가능한 구조화 패널이 있는 답변에서 내부 snake-case 경로 표식과 단독 구분선을 제거하도록 보완했다.
- 특정 의료행위, 세대, 금액 또는 UAT 질문 문자열을 제품 코드에 추가하지 않았다.

## 원문 근거 확인

- 4세대: `약관_ch_002441`, p.71의 비급여 자기공명영상진단 1년 단위 합산 한도 300만원
- 5세대: `표준약관_ch_005607`, p.400의 비급여 자기공명영상진단 1년 단위 합산 한도 200만원

위 수치는 테스트의 원문 근거 fixture에서만 확인했으며, 제품 코드나 처리 정책에 하드코딩하지 않았다.
