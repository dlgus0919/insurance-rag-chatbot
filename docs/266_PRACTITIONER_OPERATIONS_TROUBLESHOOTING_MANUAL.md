# 실무자 전체 운영 오류 대응 매뉴얼

문서 버전: 1.0
기준일: 2026-07-15

## 1. 빠른 장애 분류

이 문서는 보험 문서 검색, 일반 질의, 보험금 계산, 지식 확장 기능을 사용하는 실무자가
화면에서 확인한 오류나 검토 상태를 안전하게 분류하고 담당자에게 전달하기 위한 안내서입니다.
이 문서의 안내는 조회, 재시도, 화면 새로고침, 관리자 이관으로 한정합니다. 데이터 삭제,
인덱스 재생성, 서버 재시작, 모델 변경은 실무자 조치가 아닙니다.

대상 범위는 로그인과 권한, 화면과 API, RAG 검색, 보험금 계산, 문서 추가와 지식 확장,
검색 인덱스, GraphDB, LLM 연결, DGX 운영 상태입니다. 실제 오류 코드와 화면 문구가 있는
경우에는 그 계약을 우선하며, 전용 오류 코드가 없는 운영 상태는 관리자 확인 대상으로 구분합니다.

1. 로그인 또는 권한 문구가 보이면 `AUTH-*`, `SESSION-*` 항목을 확인합니다.
2. 화면이 멈추거나 요청이 실패하면 `UI-*`, `API-*` 항목을 확인합니다.
3. 검색 결과, 근거, 답변 생성 문제가 의심되면 `RAG-*`, `INDEX-*`, `GRAPH-*`, `LLM-*` 항목을 확인합니다.
4. 보험금 계산 결과에 검토 필요가 표시되면 `CLAIM-002`를 먼저 확인합니다. 이는 계산 엔진 오류가 아니라
   추가 확인이 필요한 업무 상태일 수 있습니다.
5. 문서 추가나 후보 생성 단계에서 멈추면 `INTAKE-*` 항목을 확인합니다.
6. 앱 자체가 열리지 않거나 관리자 시스템 상태가 비정상이면 `SYSTEM-*` 항목으로 이관합니다.

## 3. 공통 증거 수집과 보안

공통으로 남길 정보는 오류가 나타난 시각, 실행한 기능, 화면에 표시된 코드 또는 문구,
문제가 발생한 단계입니다. 고객 정보, 원문 문서, 로그인 정보는 오류 메모에 복사하지 않습니다.
