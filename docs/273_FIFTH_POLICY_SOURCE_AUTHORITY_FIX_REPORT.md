## 결론

5세대 탈모 직접 조항 검색은 기존에도 성공하고 있었습니다. 문제는 선택된 표준약관 근거와 무관하게 온톨로지의 정적 문구가 자사 5세대 약관 부재를 단정해 표시하던 것입니다.

권위 문구는 최종 직접 근거 청크의 메타데이터에서 계산합니다. 표준약관만 선택되면 등록된 5세대 표준약관의 직접 조항을 사용했다는 사실을 표시하고, 자사만 또는 자사와 표준이 함께 선택된 경우도 각각 구분합니다. 활성 온톨로지에 남아 있을 수 있는 `standard_reference_note`는 런타임 답변에서 읽지 않습니다.

## 변경 사항

- `src/rag/source_grounded_answers.py`
  - 직접 근거를 자사, 표준약관, 기타로 분류합니다.
  - 표준약관은 `is_own_company` 값이 없는 기존 인덱스도 `product_type` 또는 `doc_short` 값으로 인식합니다.
  - 정적 `standard_reference_note`를 런타임 답변에서 더 이상 읽지 않습니다.
- `src/config.py`
  - `PdfSource.policy_generation`을 위치 인자 호환성을 유지하는 후방 기본값 필드로 복구했습니다.
  - 자사 실손약관은 4세대, 표준약관은 5세대와 비자사 출처로 선언했습니다.
- 회귀 테스트
  - 표준만, 자사만, 자사+표준 혼합, 기타 출처, 낡은 프로필 문구 차단을 추가했습니다.
  - 신규 인제스트의 4·5세대 및 `is_own_company=False` 청크 메타데이터 보존을 추가했습니다.
  - 새 5세대 답변 저장과 과거 저장 메시지 불변을 격리 DB fixture로 검증했습니다.
