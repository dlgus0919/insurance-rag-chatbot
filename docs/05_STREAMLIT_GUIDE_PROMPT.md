## 붙여넣을 프롬프트

```
당신은 시니어 Python 개발자입니다. M8까지 완료된 "보험 문서 RAG 챗봇" 프로젝트에서
사용자(보험사 실무 담당자, 비개발자)가 Streamlit UI를 처음 열고 기능을 검증할 수 있도록
테스트 가이드라인 파일을 작성해주세요.

현재 프로젝트 상태 (참고):
- Streamlit UI: `streamlit run src/ui/streamlit_app.py`로 실행
- 인덱싱 완료: 심평원 2,286청크 + 약관 384청크 (합계 2,670청크)
- LLM: gemma3:4b (`.env`에 `OLLAMA_MODEL=gemma3:4b` 설정됨)
- Eval 결과: recall@8=1.000, page_accuracy≥0.600 (M8 후 목표치)
- 출처 표시 형식: [출처: 문서명, 조문/절, p.페이지]

작성할 파일: `docs/05_STREAMLIT_TEST_GUIDE.md`

가이드라인 요구사항:

[섹션 1 — 실행 전 준비]
- Ollama 앱이 실행 중인지 확인하는 방법 (메뉴바 아이콘 또는 `ollama list` 명령)
- `.env` 파일에 `OLLAMA_MODEL=gemma3:4b` 설정 확인
- 터미널에서 프로젝트 폴더로 이동 후 실행 명령:
  `streamlit run src/ui/streamlit_app.py`
- 브라우저에서 `http://localhost:8501` 접속 안내
- 첫 실행 시 모델 로딩 대기 시간 안내 (최초 1회, 30초 내외)

[섹션 2 — UI 구성 확인]
- 왼쪽 사이드바: 모델명 표시, Top-K 슬라이더(4~12), 온도 슬라이더(0.0~0.7), 대화 초기화 버튼
- 중앙 채팅창: 질문 입력란, 메시지 히스토리, 출처 expander
- 각 요소가 보이면 정상이라는 안내

[섹션 3 — 단계별 테스트 시나리오 5개]
아래 5개 질문을 순서대로 입력하고, 각 질문마다 확인 포인트를 체크합니다.

시나리오 1 — 심평원 코드 조회 (단일 문서)
  질문: "AA157은 어떤 기관의 초진 진찰료이며 점수는 얼마인가요?"
  확인 포인트:
  - 답변에 '상급종합병원'이 포함되어 있는가
  - 구체적인 점수 수치가 포함되어 있는가
  - [출처: 심평원, ..., p.101] 또는 유사한 출처 표기가 있는가
  - '출처 보기' 클릭 시 심평원 원문이 보이는가

시나리오 2 — 약관 진단코드 보상 여부 (단일 문서)
  질문: "N39.3 진단이 실손의료비 약관에서 보상가능한지 알려줘."
  확인 포인트:
  - 답변에 '요실금' 또는 'N39.3'이 언급되는가
  - '보상하지 않습니다' 또는 유사한 표현이 있는가
  - 출처가 '약관'으로 표시되는가 (심평원이 아닌 약관)
  - 질병급여/비급여/3대비급여 중 하나 이상 언급되는가

시나리오 3 — 심평원 수술코드 조회
  질문: "식도조루술의 코드를 알려줘."
  확인 포인트:
  - 코드 'Q2333'이 답변에 포함되는가
  - 출처가 심평원으로 표시되는가
  - '출처 보기'에서 식도 관련 원문이 보이는가

시나리오 4 — 약관 의미 검색
  질문: "실손의료보험 약관에서 3대비급여에 해당하는 항목은 무엇인가요?"
  확인 포인트:
  - 도수치료, 비급여 주사료, MRI/MRA 중 하나 이상 언급되는가
  - 출처가 약관으로 표시되는가

시나리오 5 — 멀티턴 연속 질문 (히스토리 누적 확인)
  이전 대화 유지 상태에서 추가 질문: "그렇다면 3대비급여 중 도수치료의 보상 한도는 어떻게 되나요?"
  확인 포인트:
  - 이전 대화 내용이 화면에 남아 있는가
  - 새 답변이 추가되는가
  - '대화 초기화' 버튼 클릭 시 히스토리가 지워지는가

[섹션 4 — 출처 expander 사용법]
- 각 답변 하단 '출처 보기' 클릭 방법
- 원문 청크에서 문서명(심평원/약관), 조문, 페이지를 확인하는 방법
- 시나리오 1(심평원)과 시나리오 2(약관)의 출처 문서명이 다르게 표시됨을 비교 확인

[섹션 5 — 이상 증상 대처]
다음 상황별 해결 방법을 표나 항목 형식으로 안내:
- "Ollama 서버에 연결할 수 없습니다" → Ollama 앱 실행 또는 터미널에서 `ollama serve`
- 응답 없음 또는 너무 느림 → 사이드바에서 Top-K를 4로 줄이고, 온도를 0.1로 낮추기
- "제공된 문서에서 확인되지 않습니다" → 질문을 더 구체적으로(코드번호 포함) 재시도
- 인덱스 오류 → 터미널에서 `python scripts/ingest.py --stage index` 재실행
- 포트 충돌 (8501 이미 사용 중) → `streamlit run src/ui/streamlit_app.py --server.port 8502`

[섹션 6 — 테스트 완료 체크리스트]
아래 항목을 모두 확인했으면 테스트 완료입니다:
□ 심평원 질문에 심평원 출처가 표시된다
□ 약관 질문에 약관 출처가 표시된다
□ 출처 expander에서 원문이 보인다
□ 연속 질문 시 히스토리가 누적된다
□ 대화 초기화 버튼이 작동한다

작성 지침:
- 독자는 비개발자(보험사 실무 담당자)입니다. 기술 용어는 괄호 안에 간단히 설명하세요.
- 각 확인 포인트는 "~이 보이면 정상입니다" 형식으로 끝내세요.
- 코드·명령어는 코드 블록(백틱)으로 표시하세요.
- 스크린샷 없이 텍스트만으로 위치를 설명하세요.
- 파일 저장 경로: `docs/05_STREAMLIT_TEST_GUIDE.md`
- 한국어로 작성하세요.

완료 후 보고서:

```
