## 0. 배경

이전 OCR 품질 전반 검토에서 일부 이슈가 코드 수정(spec #63~#65)으로 해결됐으나, 두 가지 데이터 레벨 오류가 남아있다.

**spec #65에서 해결 확인된 항목:**
- '수족골 적출술' — OCR 누락이 아님. `p063_t00.json`에 `'수 · 족골 적출술'`로 정상 수록. `_normalize_lookup_text()`의 중간점(·) 미처리 버그가 원인 → spec #65에서 코드 수정.

**남은 데이터 레벨 오류:**

| 항목 | 유형 | 영향 |
|---|---|---|
| 구형 수술분류표 오인식 | p006~p021 (14개 파일) 광범위 | C 주입 시 잘못된 종수 데이터 |
| 상담사례집 단독 숫자 청크 | 페이지 번호만 있는 노이즈 (393건) | 검색 노이즈 증가 |

이 오류들은 Parquet 또는 chunks.jsonl 데이터 자체를 수정해야 하며, 소스는 `data/extracted/실무가이드/tables/*.json` 파일들이다.

## 1. 수정 대상 및 접근법

### 1-1. 구형 수술분류표 오인식 (p006~p021)

**현황:**
- `data/extracted/실무가이드/tables/` 내 p006~p021 파일들 (14개)
- 헤더가 '수 술 홈'/'수 술 온' 등으로 오인식
- 이 파일들의 데이터가 Parquet에 포함되어 있으면, 신(新) 수술종수 컬럼 구조와 불일치 → 잘못된 C 주입 가능

**원본 위치:** `data/raw/실무가이드.pdf` p.6~21

**수정 방법 (두 가지 중 선택):**

**방법 A (단순):** p006~p021 파일들을 Parquet 빌드에서 제외
- `scripts/build_table_index.py`에서 `table_type != "old"` 필터 추가
- 또는 해당 파일들을 `table_type: "old_surgery"` 로 마킹 후 인덱스 시 스킵

**방법 B (완전 교정):** Claude 에이전트가 각 페이지 이미지 대조 후 JSON 교정
- 작업량 높음 (14페이지 × n개 표)
- 정확도는 높지만 즉각적인 eval 개선 효과는 spec #63의 `_OLD_SURGERY_TABLE_MARKERS` 가드로 이미 부분 해결됨

**권장:** 방법 A 먼저 적용 후 eval 결과 확인. 개선 미흡 시 방법 B 진행.

---

### 1-2. 상담사례집 단독 숫자 청크 (noisy chunks)

**현황:**
- `data/processed/chunks.jsonl` 중 `source: 상담사례집` 청크 1,181개 중 407개가 50자 미만
- 내용: "123\n124\n125" 형식의 페이지 번호만 있는 청크 → 검색 노이즈

**수정 방법:**
- ingest 단계에서 필터링 (코드 수정 — **spec #65에 추가 또는 별도 spec으로 처리**):
  ```python
  # 순수 숫자/공백으로만 구성된 50자 미만 청크 제외
  if len(chunk.text.strip()) < 50 and re.fullmatch(r'[\d\s\n]+', chunk.text.strip()):
      continue
  ```
- 또는 chunks.jsonl 재생성: `python scripts/ingest.py` 에 해당 필터 추가 후 재실행
